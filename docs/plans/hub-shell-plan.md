# RFC 0006：Hub 外壳、原生应用与 Lua 应用层

> 状态：H0–H2 实施中；L0–L2 待 H2 真机验收后开始。
> 范围：主页（狐狸）、应用网格、系统手势、三个原生应用（设置 / 传感器 / 计时器）、官方兼容的 Lua 应用层。
> 不在范围：Wi-Fi / 蓝牙（锁定的 esp-hal `bb239a0` 中 S31 的 `wifi`、`bt`、`phy` 均为 `not_supported`）、语音、C3 协处理器。

## 0. 决策摘要

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | **狐狸就是主页**，应用网格从主页唤出，应用全屏 | 狐狸是这台设备的身份；官方的时钟 / 天气主页依赖网络，当前做不了 |
| D2 | 原生应用用 Rust + `lvgl-ui`（LVGL 真正渲染），Lua 应用用官方 `display` 即时绘制接口 | 设置类页面需要滑杆、开关；Lua 应用是画布式小游戏，两条路径各取所长 |
| D3 | 两条渲染路径都只产出 **一帧 RGB565 画布**，由 `tasks::plane` 统一送屏 | 保持「UI 任务独占 LVGL、plane 独占屏幕」两条规则不变 |
| D4 | 系统手势只从屏幕边缘开始 | 狐狸的抚摸 / 点按在屏幕任何位置都有效，不能和页面滑动抢手势 |
| D5 | Lua 采用 Lua 5.5，兼容官方 `display` / `delay` / `system` / `json` / `storage` 子集和 `launcher.json` 包格式 | 官方 25 个 Lua 应用实际只用到这几个模块；官方 `cap_lua` 依赖 `espressif/lua ^5.5.1` |
| D6 | 离开主页后狐狸的情绪继续运行、灯光照常反应，**马达只在主页震动** | 应用里摇晃设备（如看传感器）不应一直嗡嗡震；灯光反应保持（用户要求插拔与灯光不受抑制） |

## 1. 屏幕与导航

```text
            底边上滑                  点图标
  [主页·狐狸] ───────▶ [应用网格] ───────▶ [应用]
       ▲   ◀─────────── │  ◀───────────────── │
       │    左边右滑/底边上滑      左边右滑（返回）
       └──────────────── 底边上滑（回主页）───┘
```

- **底边上滑**：手指在屏幕底部 `y ≥ 420`（狐狸画布下沿 424 之下的条带）按下，向上移动 ≥ 80 px，且垂直位移大于水平位移的 1.5 倍。主页上打开应用网格；其他页面直接回主页。
- **左边右滑**：手指在 `x ≤ 28` 按下，向右 ≥ 80 px，水平位移大于垂直位移的 1.5 倍。返回上一级：应用 → 网格，网格 → 主页。
- 从边缘开始的触摸一律由外壳持有，不交给狐狸、也不交给 LVGL；没达到阈值就松手，视为无效。
- 屏幕是圆角屏，旧版设计文档按 60 px 圆角安全区排布，本 RFC 沿用：内容至少内收 24 px，四角 60 px 内不放可点控件。

## 2. 渲染

### 2.1 画面所有者

| 页面 | 画面所有者 | 画布 | 位置 |
| --- | --- | --- | --- |
| 主页 | 狐狸渲染器（现有 `CanvasPool`） | 352×336 | (64, 88) |
| 网格 / 原生应用 | LVGL | 480×480 | (0, 0) |
| Lua 应用（L 阶段） | Lua `display` 光栅器 | 480×480 | (0, 0) |

- `PlaneJob` 增加 `x, y, width, height`，plane 在布局变化（从全屏切回狐狸）时先把狐狸画布以外的区域清成黑色。
- LVGL 从「无头」改为真正渲染：`LV_DISPLAY_RENDER_MODE_PARTIAL`，片内 480×40 绘制缓冲；`flush_cb` 把每块拷进 PSRAM 中的 480×480 影子帧，同时累计脏区。一次 `lv_timer_handler` 结束后若有脏区，从全屏画布池（2 个 480×480 槽位，PSRAM）取一个槽、整帧拷贝、发布给 plane。
- 只在 LVGL 是画面所有者时调用 `lv_timer_handler`；回到主页时狐狸子树重新挂载，渲染器和 plane 路径与现在完全一致。
- PSRAM 预算：影子帧 450 KB + 全屏池 900 KB + 狐狸池 2×231 KB ≈ 1.8 MB。

### 2.2 字体

- 西文数字沿用 LVGL 内置 Montserrat（14–48 已启用）。
- 中文：`scripts/gen-font.py` 从 Noto Sans SC（OFL）按源码里实际出现的汉字裁剪，生成 4 bpp 位图（`assets/fonts/hub-*.bin`），固件内由 Rust 实现 `lv_font_t` 的 `get_glyph_dsc` / `get_glyph_bitmap` 回调。字号 20 / 24 / 30（对应旧版设计的说明、行标签、标题）。
- 新增界面文案后重新运行脚本；缺字时 LVGL 回退到 Montserrat，且主机测试会检查所有界面字符串都能在字体里找到。

## 3. 输入

```text
INPUT (触摸样本)
   └─ shell::EdgeGestures ──┬─ 系统手势 → Nav（主页 / 网格 / 应用）
                            ├─ 主页：普通触摸 → Runtime（狐狸性格层）
                            └─ 其他页：普通触摸 → LVGL 指针输入设备
```

- `shell::gesture` 是纯逻辑，主机测试覆盖：阈值、方向、边缘外按下不触发、按下后松手丢弃、连续两次手势。
- 切换到主页时，狐狸像现在一样做一次入场动画，期间忽略触摸。
- 网格 ↔ 应用切换有 280 ms 的推入/返回滑动（`hub::transition`）：旧页复制到 PSRAM 快照，新页渲染一次，plane 每帧上传两条拼接的列带，期间 LVGL 和触摸暂停。不依赖 LVGL 动画，迁移后也能继续用。
- 离开主页后狐狸暂停：只有电量、模块插拔、松键等持久状态传给她；灯光和马达归应用所有。设置页灯光显示预览（从左到右点亮再常亮暖白），打开震动开关会振一下。

## 4. 应用模型

- `apps::AppId { Settings, Sensors, Timer }`，每个应用一个模块：`State` + `update(msg)` + `view(&State, &Theme) -> Node<HubMsg>`。
- `shell::Hub` 持有导航状态、所有应用状态和一个 `SystemSnapshot`（由 `SensorEvent` 流更新：加速度、角速度、光线、有人、电量、左右模块、磁铁状态）。
- 计时器状态在 Hub 里，不随页面卸载；倒计时在后台也继续走，结束时：马达提醒、灯光闪一下，并自动打开计时器页显示「时间到」。
- 设置项通过原子量交给对应任务：亮度 → plane，灯光开关 → lights，震动开关 → haptic。暂不持久化（重启恢复默认），持久化等存储方案定下来。

### 4.1 原生应用

| 应用 | 内容 |
| --- | --- |
| 设置 | 亮度滑杆（10–100 %）、灯光开关、震动开关、关于（版本、运行时间、内存余量） |
| 传感器 | 姿态（三轴加速度 + 倾角）、角速度、光线条、有人、电量条、左右模块、磁铁 |
| 计时器 | 预设 1 / 3 / 5 / 10 / 25 分钟、大号 `mm:ss`、圆弧进度、开始 / 暂停、重置 |

## 5. Lua 应用层（L 阶段）

运行时设计、错误处理规则、调度与模块对照见 [lua-runtime-plan.md](lua-runtime-plan.md)。

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| L0 | Lua 5.5 C 源码随 `cc` 编进固件；C 库适配层（`setjmp`/`longjmp`、`snprintf`、`strtod`、数学函数）；`lua_Alloc` 接到 Rust PSRAM 堆并设上限 | 串口跑通 `print("hi")`；记录固件增量、内存占用 |
| L1 | Lua 任务 + `display`（`begin`/`present`/填充矩形·圆·三角·圆角矩形/文字/`touch`）、`delay`、`system`、`json`；指令计数钩子限制单次运行时长 | 官方 `snake`、`game_2048` 原样运行；通过官方 `display_contract.lua` |
| L2 | `storage` 子集、`imu`、`launcher.json` 解析、应用网格显示 Lua 应用；USB 串口推送应用与热重载 | 从电脑推一个应用到板子，网格出现图标并能打开 |

- Lua 应用独占画面期间，左边右滑会抛出 Lua 错误终止脚本并回到网格；官方应用自带的退出按钮照常可用。
- 不实现官方的 `lvgl`、`gpio`、`i2c`、`http`、`ble` 模块。
- 锁定官方 `esp-claw` 的某个提交作为接口基线，升级时用契约测试检查差异。

## 7. 风险

| 风险 | 应对 |
| --- | --- |
| 全屏 LVGL 帧整帧拷贝 + 上传（约 18 ms）拖慢 UI 循环 | 只在有脏区时出帧；先测，必要时只上传脏区 |
| 中文字体占 flash | 按源码用字裁剪，三个字号预计 < 150 KB |
| 边缘手势和应用内控件冲突 | 边缘条带内不放控件；阈值留在常量里，真机再调 |
| 官方 Lua 接口仍在变 | 锁定提交 + 契约测试 |
