# v18：ikaros 界面与触控验收包

适用硬件：ESP32-S31-Korvo-1 + SUB3 800×480 RGB LCD，GT1151 触摸控制器。

## 本版内容

- 品牌统一为 `ikaros`。上电播放一次约 1 秒的标识淡入与短线展开，进入主界面后不循环播放；启动期间的触摸及跨界面长按不会触发档位选择。
- 温度历史改为连续曲线，保留最近 30 个采样点，每秒更新。纵轴固定为 15–70°C，标出 60°C 提示线与最新采样点。
- 主色使用 `#409EFF`，主卡片四角增加 14px × 2px 的 L 形短边框。
- 包含 GT1151 完整报文解析、校验及触摸诊断修正；详细协议说明见源码中的 `docs/releases/v17-touch.md`。
- 沿用已验证的显示驱动：PSRAM 双帧缓冲、4×10 行 SRAM 补块环以及 `OUT_EOF_MODE=0`，保留原时序、引脚和帧发布协议。

## 触控验收

串口使用 **115200 8N1**。冷启动后确认日志包含：

```text
ikaros 风扇控制固件启动 v18
GT1151 触摸已就绪 (I2C=100kHz, GT1151 完整报文校验)
AXI DMA TX 配置
ikaros 启动页交接完成
```

其中 `AXI DMA TX 配置` 应包含 `eof_popped=false`。

1. 主界面出现后依次点击 **0 / 25 / 50 / 75 / 100 / AUTO**，检查选中状态和占空比响应。每次点击应有 `触摸按下`、`触摸抬起`；档位变化应有 `UI 档位切换`。
2. 按住一个档位约 1 秒后抬手，再连续点按；在屏幕四角及按钮边缘按下、抬起，检查日志坐标是否对应实际位置。
3. 再次冷启动，在启动页按住并保持到主界面出现，确认没有误选档位；抬手后重新点击应能操作。
4. 保持运行并操作档位，确认温度曲线更新时画面位置稳定，显示心跳中的 `EOF失步`、`欠载`、`DMA错误` 不持续增长。

如有失效，请保存**完整开机日志、出问题时的按下/抬起与档位事件，以及随后至少一组 `心跳`、`触摸累计` 和 `触摸最近错误`（若有）**，同时记录实际点击位置与现象。`触摸累计` 中的 I2C、校验、无效报文和越界计数有助于定位问题。

## 验证范围

当前代码已通过 20 项软件测试、两种桌面布局构建、MCU release 构建与固件运行时依赖隔离检查，并完成 RGB565 软件渲染预览、曲线边界情况及启动触摸隔离检查。交付时重新执行 release 构建并校验镜像、源码清单和压缩包。

本版触控与启动效果的真机验收待完成，`BUILD.json` 中 `hardware_verified` 保持为 `false`。温度为模拟数据，转速按占空比估算；外置温度传感器及 TACH 尚未接入，实际 PWM 波形需硬件验证。
