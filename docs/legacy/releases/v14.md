# v14 版本说明（抗闪烁 + 仪表）

## 本版改了什么（相对上一包）

1. **弹跳缓冲 2 块 → 4 块**：DMA 每次读一块内部 RAM 缓冲（10 行），中断里从 PSRAM 搬下一块。
   原来只有 2 块，搬运必须在一个缓冲周期（≈515µs）内完成，实测搬运 ~178µs 且和渲染抢 PSRAM 带宽，
   一旦超时 DMA 就会读到半新半旧的缓冲 → 屏幕横向杂带。4 块把窗口拉到 ≈1546µs。
2. **发布超时不再复位**：旧版等帧边界超时会 panic → 软复位 → 黑屏重启（相当于把一次抖动放大成闪黑）。
   现在超时只是本次发布作废，屏幕继续扫旧帧，下一轮重试，画面不闪不黑。
3. **行号自愈**：中断现在按硬件上报的「刚完成的描述符地址」决定写哪一块缓冲，
   即使丢了一次中断事件也不会写进 DMA 正在扫的那块，并把行号游标按丢的块数补齐。
4. **启动自检**：等第一块缓冲搬完（200ms 超时打 error），避免一上电就走异常路径。
5. **心跳日志补全**：新增渲染/循环耗时、面板实际帧率、等帧最长、搬运最长、放弃次数、时间戳。

## 请重点验证

- **闪烁是否改善**（这是本版目标）
- 串口心跳里 `帧界` 是否 ≈35.4Hz、`搬运max` 是否 < 515µs、`放弃`/`EOF失步` 是否为 0
- 若仍闪：请把闪烁时的**心跳整行**和描述（整屏闪 / 局部条带 / 噪点）发回来。
  特别地，如果闪的是「逐像素噪点」而不是整块条带，请告知——那指向 PCLK 采样边沿而不是缓冲时序，
  代码里已留一行开关（`display.rs` 的 `PCLK_PHASE`），改一行就能做 A/B。
