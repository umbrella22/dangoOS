# v20：温度历史与曲线增量渲染

适用硬件：ESP32-S31-Korvo-1 + SUB3 800×480 RGB LCD、GT1151 触摸。

## 更新路径

温度历史达到 30 点后，v19 每秒删除第一行并新增末行。Slint 1.17.1 销毁重复项时强制刷新整窗，因此即使全部温度值不变，也会重绘 384,000 个像素。

v20 的固件和桌面端共用 `TemperatureHistory`。历史窗口原位更新已有行，仅通知数值发生变化的行；每行同时提供线段的两个端点，避免绑定通过整个模型查询相邻点。空历史、单点和逐渐增长到 30 点的显示语义保持一致。

曲线将每段 Path 的范围收紧到描边附近，同时保留原有温度比例和路径拟合。正常换帧继续使用 `SwappedBuffers`，合并最近两帧的脏区；发布超时后仍重建重绘历史。

## 软件渲染器补丁

Slint 1.17.1 的路径混合没有应用局部脏区，可能在保留的抗锯齿像素上重复叠加颜色。项目在 `vendor/i-slint-renderer-software` 中保留该版本源码，修正填充和描边的混合范围。路径蒙版保持原坐标，每个脏像素最多混合一次，重叠脏矩形不会重复处理。

`present()` 通过现有 Release/Acquire 握手发布候选帧。同核 ISR 从 PSRAM 读取像素并复制到内部 SRAM 弹跳缓冲，DMA 只读取这些 SRAM 缓冲；发布入口不再对整块 PSRAM 帧缓冲执行缓存写回。

## 软件验证

800×480 RGB565、内嵌字体、双缓冲预热后的历史独立更新测量：

| 场景 | v19 重绘像素 | v20 重绘像素 |
| --- | ---: | ---: |
| 30 个相同温度值继续滚动 | 384,000 | 0 |
| 原位修改最后一个点 | 28,028 | 102 |

v20 连续 100 次模拟温度滚动中，单帧最大重绘 2,622 像素，且每帧与完整重绘结果逐像素一致。此测量只更新历史曲线；实际每秒界面还会更新温度文字、运行时间和其他数据。

原曲线对照覆盖空历史、单点、水平线、上下限、上升下降斜线、锯齿和缓慢波形。9 组场景合计 8 个 RGB565 像素存在抗锯齿浮点取整差异，RGB888 最大通道差异为 1/255。局部绘制与同版完整绘制的比较不允许任何像素差异。

软件检查覆盖历史顺序、双缓冲、发布撤回、文字灰度抗锯齿、路径脏区混合、触摸协议、两种桌面布局以及 MCU release 构建。发布包记录 vendored 渲染器源码哈希。

## 真机验证边界

主机重绘像素数不代表 MCU 渲染耗时或触摸延迟。实际改善幅度需在设备上记录稳定运行超过 30 秒后的触摸间隔、渲染耗时和 LCD/DMA 计数，`hardware_verified` 保持为 `false`。

静止文字红边的面板根因尚未确认。原始 RGB565 彩条诊断入口 `lcd-color-test` 保留；本次路径混合修正不构成对静态文字红边的真机结论。
