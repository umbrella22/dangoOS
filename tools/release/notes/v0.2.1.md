dangoOS v0.2.1 为 ESP-Mosaico V1.2 / ESP32-S31 提供可校验的 OTA 升级包和全量安装包。

- 使用 crates.io 的 `rs_lvgl` / `rs_lvgl_ui` 0.2.0，并统一 Rust 依赖名称。
- 将 Lua 引擎测试资料集中到 `crates/lua-engine/test/`，明确运行依赖、测试和接口参考的边界。
- 增加 GitHub Actions：分支与 PR 执行测试、固件构建和打包；推送匹配工程版本的 tag 后自动发布。
- 全量包更新到官方 Mosaico Bootloader v2 的 2026-10-21 构建，保留同一官方底包的 Vibe Mode 和工厂 UI 资源。

下载 `*-ota.zip` 可获得应用镜像和 USB OTA 工具，适用于已经采用 dangoOS A/B 布局的设备；它保留 BL、system 应用和用户数据。
下载 `*-full.zip` 用于首次安装或完整恢复，内含从地址 **0x0** 写入的 **16 MiB** 镜像；**全量安装会清除用户数据和下载应用**。
独立的 `*-ota.bin`、`*-full.bin` 供已有工具使用，类型和写入方式不可混用。

安装步骤见 `INSTALL.md`；`manifest.json` 记录源码提交、分区和官方组件来源；下载后核对 `SHA256SUMS`。
发布流程执行主机回归、固件构建、应用文件树、镜像格式和发布附件回读校验。
本次未刷写设备，新 BL 的整机首次安装及工厂恢复入口未进行本轮硬件验收。
