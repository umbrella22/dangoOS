dangoOS v0.4.2 将 LVGL Rust 依赖升级至公开的 0.5.0，并适配设置开关事件与可选诊断构建。下载包使用默认 Lua 固件，包含五个 Lua 应用、匹配字体和四套团子资源。

## 界面与依赖

- rs_lvgl、rs_lvgl_ui、rs_lvgl_sys 和 rs_lvgl_codegen 统一使用 crates.io 的 0.5.0，原生实现继续使用 LVGL 9.6。
- 设置开关通过 `on_toggle(bool)` 传递选中状态，复用现有消息队列、模型更新和受控状态回写。
- EmbedScope 沿用应用已有的 `TreeSource`，从系统正在使用的 LVGL 实例采集界面树。`escope-lvgl` 使用默认 feature 集，普通固件和诊断构建都只解析一套原生 LVGL provider。
- EmbedTS 和 EmbedScope 继续作为源码构建选项，公开下载包使用 Lua，关闭诊断接口。

## 安装与兼容性

从 v0.4.0 或 v0.4.1 升级无需重新分区，布局继续使用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND`，两个应用槽各为 6 MiB，可写数据位于独立 NAND。

日常升级下载 `dangoOS-v0.4.2-esp32s31-ota.zip`，按包内 `INSTALL.md` 更新非活动槽，并检查版本与启动健康状态。使用包内安装器安装匹配字体和团子资源；Data 应用仅在显式添加 `--update-apps` 时更新。OTA 与资源安装保留照片、存档、偏好和团子选择。

首次安装、v0.2.1 旧布局迁移或恢复使用 `dangoOS-v0.4.2-esp32s31-full.zip`。全量镜像覆盖 NOR 上的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 数据；安装前备份旧 NOR 数据。NAND 格式化仍须显式指定。

## 校验与验证范围

发布流程核验工作区与 Python 测试、独立驱动、Lua / TS 固件构建、引擎互斥与符号隔离、镜像资源预算，以及 OTA / 全量安装包。附件上传后重新下载并核对清单与 SHA-256。

下游适配另行检查默认与诊断依赖图、主机原生 UI 交互、字体和资源生命周期，以及 ESP32-S31 诊断配置编译。主机渲染和目标构建分别记录。本版发布制品未执行实体设备安装验收，状态记录于 `manifest.json.hardware_validation`。
