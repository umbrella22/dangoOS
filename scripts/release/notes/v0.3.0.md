dangoOS v0.3.0 为 ESP-Mosaico V1.2 / ESP32-S31 增加无线连接、原生设置、四种团子形象和 NAND 用户存储，并改善内存保护与 CPU 功耗管理。

## 新功能

- **原生设置**：管理亮度、音量、灯光、震动、Wi-Fi、蓝牙、相机、存储和团子选择，自动保存偏好并显示保存结果。
- **Wi-Fi 与系统更新**：支持 2.4 GHz WPA2 网络，在「设置 → 系统更新」中检查并安装兼容的新固件；支持 HTTP CONNECT 代理和 A/B 升级。
- **蓝牙音频**：开启蓝牙后连接 `ESP-Mosaico Audio`，通过板载扬声器播放音乐，支持配对与音量同步。
- **团子状态**：主页顶部显示 Wi-Fi、蓝牙连接状态和 Wi-Fi 信号强度；连接成功的表情显示 4 秒后恢复常规表情，音乐播放参与表情调度。
- **四种形象**：内置「鸣潮 · 心月狐团子」，发布 ZIP 同时提供「玄灵 · 月蚀」「玄灵 · 常态」「智谱团子」三套 NAND 资源，切换后保留选择。
- **相机与相册**：支持左槽 OV3640 / SC101IOT 模块预览、JPEG 拍照及 Photo 应用。照片、存档和偏好存放在独立 NAND 中。

## 性能与稳定性

- 双核共享 CPU 时钟按需在 **160 / 320 MHz** 间切换，依据交互、渲染和 Lua 计算开销请求性能，等待定时器、UI 或 DMA 时释放请求。
- 修复进入「关于设备」时的卡死，可用内存由服务线程按请求读取。
- 为前台 Lua VM、worker 和原生像素资源分别设置限额，补齐内存增长、分配失败和应用退出清理的回归覆盖。
- 按应用、硬件平台、系统服务、团子行为和页面外壳重组源码，保留单一 LVGL 调用线程与双核任务分工。
- 移除历史诊断 feature、设备探针、故障注入、测试命令、寄存器转储和周期性能采样；正式构建关闭 Debug / Trace 日志，保留故障记录、资源保护和 OTA 启动健康检查。

## 安装与升级

**从公开的 v0.2.1 升级，需要先使用全量包迁移分区布局。** v0.2.1 使用两个 3 MiB 应用槽；v0.3.0 改为两个 6 MiB 应用槽和独立 NAND 用户存储，旧布局无法直接安装本版 OTA 镜像。迁移前备份旧 NOR 中的应用、照片、存档等用户数据；全量安装不会自动将这些数据迁入 NAND。

- 首次安装、旧布局迁移或完整恢复：下载 `dangoOS-v0.3.0-esp32s31-full.zip`，按包内 `INSTALL.md` 执行安装。完整镜像为 **16 MiB**，从 NOR 地址 **0x0** 写入。
- 已采用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND` 布局的设备：可使用 `dangoOS-v0.3.0-esp32s31-ota.zip` 及其 USB 工具更新非活动槽，保留现有 system 和 NAND 数据。
- 两个 ZIP 都包含三套 NAND 团子及安装器。无线 OTA 和独立 BIN 不安装这些资源；通过 ZIP 中的 `install.py` 更新，保留当前团子选择。
- 内置应用和默认形象位于 NOR 的 system 分区，更新它们需使用全量包。

全量安装覆盖 NOR 中的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 中已有的数据。全新或无法挂载的 NAND 需要显式初始化；`--format-nand` 会清空该卷，具体条件与操作见包内说明。

## 发布文件与校验

发布页提供 OTA BIN、全量 BIN、两个 ZIP、`INSTALL.md`、`manifest.json` 和 `SHA256SUMS`。下载后先核对 SHA-256；镜像类型和写入方式不可混用。

`manifest.json` 记录源码提交、镜像结构、分区、官方组件来源与三套 NAND 资源的版本和哈希。发布流程执行主机回归、固件构建、资源解码、安装包独立校验和 Release 附件回读校验。发布包的硬件验收状态记录在 `hardware_validation` 中。
