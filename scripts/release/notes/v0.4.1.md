dangoOS v0.4.1 升级 LVGL Rust 依赖，接入独立 EmbedTS 引擎，并整理脚本宿主与诊断能力。发布包提供默认 Lua 固件、五个内置 Lua 应用、匹配字体和四套团子资源。

## 界面与运行时

- rs_lvgl、rs_lvgl_ui 及其原生依赖统一升级至 0.4.0，适配 `App::Action` 和新版样式接口。
- Lua 与 EmbedTS 通过共享 `app-host` 接入图像、硬件和原生 UI。新增脚本内存、调度、界面批次及资源释放回归，完善触摸报告解析和输入同步。
- 内置应用保持 `apps/<分类>/<id>/` 的 Lua 源码结构，应用导出、图标工具和示例使用一致路径。

## 可选开发配置

- `ts-engine` 通过固定的 GitHub 完整提交接入 [EmbedTypescript](https://github.com/umbrella22/EmbedTypescript)，支持经过校验的 `.etb` 应用与常驻行为。编译器、SDK 和 TypeScript 源码在该独立仓库维护；dangoOS 的构建和测试读取预编译输入。
- 每份固件选择 Lua 或 EmbedTS 中的一个引擎。发布下载包使用默认 Lua 配置，TS 固件可通过源码中的 `cargo fw-ts` 构建。
- `embedscope` 是默认关闭的诊断选项，依赖升级至 0.2.0，提供独立 USB CDC、日志、指标、界面树和屏幕采集。发布下载包不启用该选项。

## 安装与兼容性

从 v0.4.0 升级无需重新分区，布局继续使用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND`，两个应用槽各为 6 MiB，可写数据位于独立 NAND。

日常升级下载并解压 `dangoOS-v0.4.1-esp32s31-ota.zip`，按包内 `INSTALL.md` 更新非活动槽并检查版本与启动健康状态。使用包内安装器补装匹配字体和团子资源；Data 应用仅在显式添加 `--update-apps` 时更新。OTA 与资源安装保留照片、存档、偏好和团子选择。

首次安装、v0.2.1 旧布局迁移或恢复使用 `dangoOS-v0.4.1-esp32s31-full.zip`。全量镜像会覆盖 NOR 上的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 数据；安装前备份旧 NOR 数据。NAND 格式化仍须显式指定。

TS 的旧 `.rsts` 应用需要使用匹配的 EmbedTS 构建器重新构建为 `.etb`。默认 Lua 发布包继续运行 Lua 应用，切换引擎需要匹配的固件与应用产物。

## 校验与验证范围

发布流程执行工作区与 Python 测试、独立驱动检查、Lua / TS 固件构建、引擎互斥与符号隔离、镜像资源预算，以及 OTA / 全量安装包的独立校验。下载后先核对 `SHA256SUMS`。

本版发布制品未执行实体设备安装验收；具体状态记录于 `manifest.json.hardware_validation`。既有设备记录对应此前镜像，不代表本版制品已通过设备验收。
