dangoOS v0.4.3 将 LVGL Rust 依赖升级至正式发布的 0.6.0，适配新的界面命名、布局和样式接口。下载包继续使用默认 Lua 固件，包含五个 Lua 应用、匹配字体和四套团子资源。

## 界面与源码迁移

- rs_lvgl、rs_lvgl_ui、rs_lvgl_sys 和 rs_lvgl_codegen 统一使用 crates.io 的 0.6.0，原生实现继续使用 LVGL 9.6。
- 普通容器和进度条改用 `container()`、`progress_bar()`；滚动方向和对齐方位使用完整命名。普通节点直接链式设置属性，可复用卡片样式继续保留。
- 旧 `flex_align(main, cross)` 对应三个独立属性：`justify_content(main)`、`align_items(...)`、`align_content(cross)`，以保持现有主轴和交叉轴位置。
- 图标缩放使用 `Scale::percent(50)`，两个轴使用相同比例，保留中心 pivot 与布局空间。滑块、开关使用 `thumb_style`，滑块和进度条使用 `progress_style`；颜色补丁保留原生圆形滑钮半径，卡片为端点留出绘制空间。
- Arc、键盘和滚动条通过 `NativePart` 配置。保存反馈 spinner 继续由 UI 管理的原生工厂创建；应用和可选诊断均复用同一原生 LVGL provider。
- 上游不保留旧 API 别名，源码开发者应参考 [0.6.0 迁移文档](https://umbrella22.github.io/rs_lvgl_website/guide/ui-api-migration.html)。EmbedTS 和 EmbedScope 仍为源码构建选项，公开下载包使用 Lua，关闭诊断接口。

## 安装与兼容性

从 v0.4.0 至 v0.4.2 升级无需重新分区，布局继续使用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND`，两个应用槽各为 6 MiB，可写数据位于独立 NAND。

日常升级下载 `dangoOS-v0.4.3-esp32s31-ota.zip`，按包内 `INSTALL.md` 更新非活动槽，并检查版本与启动健康状态。使用包内安装器安装匹配字体和团子资源；Data 应用仅在显式添加 `--update-apps` 时更新。OTA 与资源安装保留照片、存档、偏好和团子选择。

首次安装、v0.2.1 旧布局迁移或恢复使用 `dangoOS-v0.4.3-esp32s31-full.zip`。全量镜像覆盖 NOR 上的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 数据；安装前备份旧 NOR 数据。NAND 格式化仍须显式指定。

## 校验与验证范围

发布流程核验工作区与 Python 测试、独立驱动、Lua / TS 固件构建、引擎互斥与符号隔离、镜像资源预算，以及 OTA / 全量安装包。附件上传后重新下载并核对清单与 SHA-256。

下游验收使用发布的 registry 包，分别检查默认和诊断依赖图、实际设置页面的原生交互、字体与资源生命周期、圆形滑钮和端点绘制，以及 ESP32-S31 目标构建。本版发布制品未执行实体设备安装验收，状态记录于 `manifest.json.hardware_validation`；主机渲染和目标构建不代表设备验收。
