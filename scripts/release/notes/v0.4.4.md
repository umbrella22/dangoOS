dangoOS v0.4.4 将 LVGL Rust 依赖升级至正式发布的 0.7.0，适配新的自定义控件属性与时间推进接口。下载包使用默认 Lua 固件，包含五个 Lua 应用、匹配字体和四套团子资源。

## 界面与源码迁移

- rs_lvgl、rs_lvgl_ui、rs_lvgl_sys 和 rs_lvgl_codegen 统一使用 crates.io 的 0.7.0，原生实现继续使用 LVGL 9.6。现有控件 feature、原生初始化与字体输入保持一致，应用与可选诊断共用一个 LVGL provider。
- 团子和开机动画显式声明 `CustomWidget::Props = ()`，调用方使用 `custom(widget, ())`。动态状态继续由共享的 `FoxControl` 和 `SplashControl` 管理，`apply_props()` 不消耗动画时间，原 `update(object, elapsed_ms)` 改为 `tick(object, elapsed_ms)`。重复协调保留已挂载实例，画布与缓冲区继续遵守原生删除回调的生命周期要求。
- 同步自定义控件创建失败和资源回收探针，移除旧版 `CustomObject::new` 的兼容注解。回归覆盖开机动画、团子帧节奏、重复协调、页面切换和卸载。
- 本项目未使用上游已删除的 chart 多参数构造器，也没有手写 `WidgetKind::Textarea` 字面量。上游完整的 0.7.0 变更见[迁移文档](https://umbrella22.github.io/rs_lvgl_website/guide/ui-api-migration.html)。源码直接使用新 API，不提供 0.6 兼容层。
- 新版上游的范围滑块、图表、文本编辑和 Flex 扩展未作为本次升级的新界面功能。Lua PCM 输出接口仍未实现，本次依赖升级不恢复游戏音效。

## 安装与兼容性

从 v0.4.0 至 v0.4.3 升级无需重新分区，布局继续使用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND`，两个应用槽各为 6 MiB，可写数据位于独立 NAND。

日常升级下载 `dangoOS-v0.4.4-esp32s31-ota.zip`，按包内 `INSTALL.md` 更新非活动槽，并检查版本与启动健康状态。使用包内安装器安装匹配字体和团子资源；Data 应用仅在显式添加 `--update-apps` 时更新。OTA 与资源安装保留照片、存档、偏好和团子选择。

首次安装、v0.2.1 旧布局迁移或恢复使用 `dangoOS-v0.4.4-esp32s31-full.zip`。全量镜像覆盖 NOR 上的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 数据；安装前备份旧 NOR 数据。NAND 格式化仍须显式指定。

## 校验与验证范围

发布流程执行工作区与 Python 测试、独立驱动、Lua / TS 固件构建、引擎互斥与符号隔离、镜像资源预算，以及 OTA / 全量安装包验证。附件上传后重新下载并核对清单与 SHA-256。

项目自身的原生回归覆盖动画生命周期、真实设置页面的输入、滑钮完整轮廓、字体和图像资源释放；默认构建与可选诊断构建分别检查依赖和 feature。公开下载包使用 Lua，关闭诊断接口。流水线产物的实体设备验收状态记录在 `manifest.json.hardware_validation`，主机渲染、目标构建和上游验收均不代表该产物的设备验收。
