dangoOS v0.6.0 将团子行为统一交给 Rust，并优化显示缓冲和帧提交。发布默认值为 RGB565、40 MHz QSPI、正常 TE 与 450 KiB PSRAM PARTIAL 绘制缓冲；前台应用继续使用默认 Lua 引擎，显示计量与 EmbedScope 诊断关闭。

## 团子行为改为 Rust

- 传感器、触摸、情绪、个性、平衡转向、表情、灯光和震动由固件内的 Rust 状态机处理，行为随固件更新。
- 移除 Lua 和 TS 常驻大脑、默认行为脚本、示例及其打包资源，移除 `brain-begin`、`brain-commit`、`brain-reload` 和 `brain-default` 等脚本修改入口。主机控制台不再提供 `brain-push`、`brain-reload`、`brain-default`。
- `brain-status` 保留为只读诊断，返回 `active=rust source=firmware`。设备上的旧行为文件不再加载，也不会自动删除。
- Lua / TS 前台应用接口与各自引擎继续保留；`cargo fw-ts` 仍可选择 TS 应用引擎。选择应用引擎不会改变 Rust 团子行为。
- 保留慢转后的爬动、停稳、快速翻转时的惊慌抓握、掉落压扁和恢复动作，整合此前尚未公开发布的团子表情、双手和转向修正。

这是脚本行为接口的兼容性变化。依赖旧大脑上传或热替换的工具需要改为更新固件，不能继续使用旧脚本控制团子。

## 显示与性能

- RGB565 的双核默认构建使用 450 KiB PSRAM 绘制缓冲，保留 LVGL PARTIAL 模式与独立影子帧，减少小分带反复准备绘制任务的开销。
- 优化帧缓冲直传、PSRAM 像素打包与 DMA 重叠、角色解码和状态同步；连接图标随团子同一帧上传，避免背景擦除后补画造成的闪烁。
- 增加可选 RGB888 局部控件路径，修复 CO5300 两行窗口对齐引发的静态横线。RGB888、53.3 MHz 超频和小区域绕过 TE 均为独立实验选项，不作为发布默认值。
- 修正诊断自动切页的目标页准备顺序，避免自动循环结束时残留旧页图案。
- rs_lvgl、rs_lvgl_ui、rs_lvgl_sys 和 rs_lvgl_codegen 统一使用 crates.io 的 0.8.0。

相同皮肤、实时传感器、名义 40 MHz、RGB565、TE、33 ms Home 目标节奏和 450 KiB 缓冲下，按 Lua → Rust → Lua → Rust 交替上机测量，四轮测量分段共记录 2,980 帧：

| 项目 | Lua 团子行为 | Rust 团子行为 |
| --- | --- | --- |
| 团子页平均上传完成帧率 | 12.45 FPS | 24.33 FPS |
| 团子页 UI 循环中位耗时 | 72.1–73.1 ms | 34.2–34.4 ms |
| 启动器 / 设置转场平均完成帧率 | 19.88–19.99 FPS | 20.01–20.02 FPS |
| 设置列表滚动平均完成帧率 | 11.14–11.31 FPS | 12.03–12.08 FPS |

团子页平均完成帧率提高约 95%；其他页面的改善较小。Rust 团子页完成间隔 p50 为 32.7–35.5 ms、p95 为 65.3–68.0 ms，尚未达到稳定 30 FPS。以上是软件记录的上传完成时间，不是光学帧率；SCLK 频率和脉宽未做电气测量。已有 DMA 时间戳低于名义数据传输下限的现象尚未解释，不能用该区间反推实际总线速度。详细口径见 [显示管线记录](../../../crates/os/DISPLAY_PIPELINE.md#rust-行为运行时对照2026-11-13)。

## 安装与资源

沿用 v0.5.0 的 `S31ONE03`，即独立 Recovery 与单个 12 MiB 主应用分区。

- 已采用 `S31ONE03` 的设备可通过 Recovery 安装 `main` 包，主应用更新保留用户数据。需要同步团子和字体时，使用 ZIP 内安装器补装配套资源。
- v0.4.4 及更早的 A/B 布局必须使用 `full` 包迁移，不能通过旧 OTA 或本版 `main.bin` 改变分区布局。
- `full` 包覆盖 NOR 系统及配置；独立 NAND 不在 NOR 写入范围。安装器只有在显式传入 `--format-nand` 时才会初始化 NAND。
- 四套团子、应用、字体与 USB 工具随 ZIP 提供，使用前核对包内 `INSTALL.md`、`manifest.json` 和 `SHA256SUMS`。

## 验证范围

Rust 迁移对应源码的完整主机检查通过 1,148 次 Rust 测试执行、4 次既有忽略及 128 项 Python 测试；补充 RGB888 库 388 项、RGB565 绘制缓冲边界和 EmbedScope 9 项测试通过。RGB565 / RGB888 各 107 帧增量上传回放与完整帧逐像素一致，Lua / TS 应用引擎的主机测试、release 交叉构建及符号隔离检查通过。正式 tag 的流水线重新执行检查、构建并校验发布制品。

版本号提升前、采用相同 Rust 行为与显示源码的普通候选已完成实体设备主应用安装、完整读回、`Ready` 启动、软件重启和三轮灭屏唤醒；前台 Lua Snake 启动、运行和停止通过，旧脚本行为修改命令被拒绝。此前显示候选的拖动、转向与返回画面已获人工确认；最终 Rust 候选的动作手感和画面观察仍待人工确认，不能以串口健康状态代替。

交替性能测试关闭音频和蓝牙，本轮没有音频连续性或 TS 前台固件的实体复测，也没有对最终发布的 full 包执行设备全量重装。发布制品与实体候选的身份、版本和校验和应分别核对，不能将候选验收视为所有发布制品的设备验收。
