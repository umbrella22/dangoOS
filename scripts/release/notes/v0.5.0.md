dangoOS v0.5.0 引入独立 Recovery、12 MiB 单主应用、启动首屏与流式 AI 会话，并修复关机和蓝牙故障恢复。发布包使用默认 Lua 固件，包含五个 Lua 应用、匹配 UI 字体和四套团子资源。

## 升级前核对布局

**v0.4.4 及更早的 A/B 布局必须下载 `dangoOS-v0.5.0-esp32s31-full.zip`，进入 ROM 下载模式后按包内 `INSTALL.md` 全量迁移。旧版无线 OTA 和本版 `main.bin` 均不能完成布局迁移。**

新布局为 `S31ONE03`：独立 Recovery、单个 12 MiB 主应用和 system 资源卷。全量安装替换 NOR 引导、分区、Recovery、主应用和 system，重置 NOR 配置。独立 NAND 不在 NOR 写入范围，照片、存档和团子选择保留；迁移前仍需备份需要的数据。无法挂载 NAND 时安装器退出，仅显式 `--format-nand` 才会初始化可丢弃卷。

已经采用 `S31ONE03` 的开发版设备可使用 `dangoOS-v0.5.0-esp32s31-main.zip`，通过 Recovery USB 更新主应用，或在设置中使用无线更新。main 更新范围限于主应用与启动记录；需要安装或更新 Recovery、引导与 system 时使用 full 包。

## 启动与救援

- 二级引导先绘制静态狐狸标识，主应用保留屏幕内容并接管显示，播放轨道微动后进入团子界面。ROM 阶段没有应用图像，首屏仍需等待二级引导完成必要初始化。
- Recovery 使用独立的屏幕、触摸、USB 和逐帧彩色动画。默认只读导出 NOR、包含 OOB 的 raw NAND、逻辑卷和可挂载文件；显式进入安装模式后才写主应用及启动记录。
- 更新先完整预检，再写入并完整读回，成功后提交 `Trial`。主系统持续健康 30 秒后提交 `Ready`；中断安装、未确认试启动和人工救援请求进入 Recovery。
- 单主应用更新会覆盖原程序。失败后的恢复路径是进入 Recovery 重新安装，设备不再保留一个完整的旧版应用槽。

## AI 会话与电脑技能

- 增加 Rust AI 会话页面，支持兼容 Responses 的流式文本、推理、工具结果和取消。设备工具提供状态读取、音量和亮度控制。
- AI 中文页面需要单独安装完整 20px 中文字库，普通 UI 字体包不包含该资源。源码中的 `scripts/assets/gen_voice_font.py` 可从 Noto Sans SC Regular 生成字库，再通过 `tools/console.py voice-font-push <voice-20.bin> --port RUNTIME_PORT` 安装；模型服务仍需另行配置。
- 当前回复完整保存至 NAND，界面只保留 UTF-8 阅读窗口。客户端不设置输出令牌或正文总长上限；实际存储容量、供应商上下文和 I/O 错误仍会明确失败。下一次任务替换当前记录，不提供历史列表或长期记忆。
- 电脑端 Responses 桥接支持 `list_skills`、`create_skill` 和 `run_skill`。首版技能是经验证的零参数设备 API 组合，支持模拟、原子安装及实际执行；能力范围限于状态、音量和亮度。
- 设备直连模式从私有运行期配置读取凭据，电脑桥接模式的模型 key 保留在电脑端。发布包不包含模型服务凭据。API 调用使用配置方的服务与账户，不提供内置免费额度。
- 按 AI 键录音、流式传输与 ASR 接入代码已具备。实际语音转写、关键词唤醒、TTS、播放中语音打断，以及 DSH、OpenClaw、自有 Rust pi 后端均不属于已完成的验收范围。

## 稳定性修复

- 修复长按 AI 键关机时的灯光终止确认与电源保持引脚收尾。
- 蓝牙线程栈分配失败返回错误，避免分配 panic；BTU worker 未初始化时跳过无效析构。
- 蓝牙故障由系统完成停止、资源释放与退避重试，主动关闭取消重试。独立生命周期工作线程让文件系统继续处理任务。永久不返回的原生调用仍可能需要 RESET。
- 保留统一扬声器输出保护，逻辑音量 0–100 映射至最高 `-15 dB`；本次没有重新标定扬声器上限。

## 制品与验证范围

发布页提供 main/full BIN、两个资源 ZIP、`manifest.json`、`INSTALL.md` 和 `SHA256SUMS`。安装前核对校验和；main BIN 与 full BIN 的写入位置及用途不同。镜像使用完整性校验，当前制品没有发布者数字签名。

流水线执行 Rust、原生 UI、Python、驱动、应用与资源检查，构建 Lua/TypeScript 固件、独立 Recovery 和固定 IDF 引导，并独立重建校验安装包。公开附件从 Release 下载后再次校验。

此前开发镜像已完成启动动画、触摸与设置、关机、Recovery 读取安装、文本模型与工具、电脑技能、蓝牙自动恢复和实际音乐播放的设备验证。不同制品的验收结果分别留档；本发布制品的设备验收状态以 `manifest.json` 的 `hardware_validation` 为准。ASR、长期内存压力和完整共存场景仍需继续验收。
