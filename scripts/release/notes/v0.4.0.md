dangoOS v0.4.0 将完整团子和 UI 字体移到独立 NAND 资源包，增加统一扬声器输出保护，并修复首页呼吸动画的矩形扫描感。

## 界面与音频

- Wi-Fi 与蓝牙图标移到团子上方的独立留白，避免与表情重叠；Wi-Fi 用亮起的弧线表示信号强度。
- 呼吸缩放使用 RGB565 双线性插值，减少细线在整数采样边界跳变，消除脸部和头发中的方框扫描感。
- 所有扬声器音量来源共用输出上限，包括蓝牙远端音量、设置和 Lua 应用。逻辑音量仍为 0–100，初始 DAC 上限为 −15 dB；该值为保守衰减，仍需实际扬声器标定。
- 系统内置狐狸团子虚影与居中问号，在启动等待、资源加载或所选资源不可用时显示；设置中可主动选择「团子虚影」。

## 独立资源与应用接口

- 「鸣潮 · 心月狐团子」「玄灵 · 月蚀」「玄灵 · 常态」「智谱团子」全部由 NAND 资源包提供，固件和新 system 镜像保留虚影图。心月狐继续使用 `default` ID，原有选择记录保持兼容。
- 完整 UI 字体独立安装，固件保留恢复字体。字体按内容哈希命名并校验，匹配资源提交后在重启时生效，旧字体保留供固件回退使用。
- 两个发布 ZIP 都提供四套团子、匹配字体、Lua 应用 bundle 及 USB 安装工具；资源清单记录版本、大小和哈希。
- Lua 应用可查询宿主能力、服务状态和资源限额，并按权限调整音量与静音。原生 Rust 模块和新增宿主能力仍通过固件更新。
- 应用脚本、图片及图标可独立更新到 Data，覆盖 system 中的同 ID 应用；卸载 Data 更新可恢复 system 版本。资源更新通过 USB 工具完成。

## 稳定性与开发验证

- 升级至 rs_lvgl 0.3.0，共享页面标题使用静态文本，连续音量与亮度事件合并相邻值，相机服务命令按视觉影响刷新界面。
- 修复压缩团子包校验时的服务线程栈溢出，解压状态直接在堆上初始化，并在单包校验中复用。
- 增加真实页面事件、严格属性、动态图片与字体生命周期的主机验收入口，以及固件槽位、内部 RAM、最大连续空闲块和资源预算检查。

## 安装与升级

**从 v0.3.0 升级无需重新分区，但应补装本版字体与团子资源。** 布局继续使用 `MOSAICO_S31_AB_LAYOUT_V2_6M_NAND`，两个应用槽各为 6 MiB，可写用户数据位于独立 NAND。

下载并解压 `dangoOS-v0.4.0-esp32s31-ota.zip`，按包内 `INSTALL.md` 更新备用槽、检查启动健康状态，再运行 `python3 install.py --port RUNTIME_PORT` 安装匹配字体与四套团子，最后重启使字体生效。安装器保留照片、存档、偏好和当前团子选择。

无线 OTA 和独立 BIN 仅更新应用固件。首次从内嵌字体版本升级而未补装资源时，界面使用恢复字体；缺少 NAND 团子包时显示虚影并保留原选择。补装后重新加载或重启恢复。需要同时更新发布包中的 Lua 应用时，为安装器添加 `--update-apps`；默认保留现有 Data 应用。

**v0.2.1 的旧版双 3 MiB 布局仍需通过全量包迁移。** 首次安装、旧布局迁移或恢复使用 `dangoOS-v0.4.0-esp32s31-full.zip`。全量镜像从 NOR 地址 `0x0` 写入，覆盖 NOR 上的系统、分区、引导信息和 Wi-Fi NVS，保留独立 NAND 中的数据；迁移前备份旧 NOR 用户数据。NAND 仅在显式使用 `--format-nand` 且卷未挂载时初始化，该操作会擦除该卷。

## 文件与校验

安装文件包括 OTA BIN、全量 BIN、两个 ZIP、`INSTALL.md`、`manifest.json` 和 `SHA256SUMS`。下载后先检查 SHA-256。固件构建、资源解码和安装包独立校验分别执行；具体镜像的硬件验收状态以 `manifest.json.hardware_validation` 为准。
